# ANet VPN — локальный проект и эксплуатация

Здесь собраны исходники ANet и локальные материалы по развертыванию
операторского контура. Исходный проект и его лицензия описаны в
[upstream README](README.md); сведения о происхождении — в [UPSTREAM.md](UPSTREAM.md).

## Состав

- исходники клиента, сервера, auth и веб-панели ANet из upstream;
- безопасные шаблоны локального WebUI/AHTTP-развертывания — [`ops/webui/`](ops/webui/);
- текущая карта сервисов и проверенные на дату записи параметры — [`docs/operations-current.md`](docs/operations-current.md);
- заметка о планшетном Android-клиенте — [`docs/android-tablet.md`](docs/android-tablet.md).

## Секреты и публикация

Из локальной установки не включены `.env`, пароли, SSH-ключи, дампы БД,
пользовательские конфигурации клиентов и APK. `.env.example` содержит только
заглушки. В upstream-исходниках могут встречаться демонстрационные значения и
тестовые ключи — не используйте их в рабочей сети. Перед любым push проверьте
`git status` и diff: документы также содержат адреса и схему инфраструктуры.

Локальная копия намеренно создана без Git remote. Не настраивайте публичный
remote, пока не удалены или не обобщены частные сведения в `docs/` и `ops/`.

## Локальный WebUI

Пример compose-файла рассчитан на запуск из каталога `ops/webui` после создания
там `.env` на основе [шаблона](ops/webui/.env.example) и задания уникальных
значений. Не запускайте его поверх
существующих контейнеров/томов, не сверив сначала compose-проект и состояние
PostgreSQL. Операционный порядок и ограничения доступа описаны в
[`ops/webui/README.md`](ops/webui/README.md).
