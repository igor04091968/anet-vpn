# ANet VPN — эксплуатационные заметки

Эта заметка описывает локальное развёртывание ANet. Исходный проект начался как
форк `ZeroTworu/anet`; сейчас код публикуется в
[`igor04091968/anet-vpn`](https://github.com/igor04091968/anet-vpn). История
форка и лицензия описаны в [`UPSTREAM.md`](UPSTREAM.md).

## Состав

- исходники клиента, сервера, auth и веб-панели ANet из upstream;
- безопасные шаблоны локального WebUI/AHTTP-развертывания — [`ops/webui/`](ops/webui/);
- текущая карта сервисов и проверенные на дату записи параметры — [`docs/operations-current.md`](docs/operations-current.md);
- заметка о планшетном Android-клиенте — [`docs/android-tablet.md`](docs/android-tablet.md).

## Рабочие данные

Репозиторий публичный. Файлы `.env`, пароли, SSH-ключи, дампы базы,
пользовательские конфиги и APK в него не добавляются; шаблоны содержат только
публичные адреса или заглушки. В эксплуатационных заметках могут быть IP-адреса
и сведения о конкретных сервисах. Проверяйте их перед публикацией новых данных.
Демонстрационные значения и тестовые ключи из исходников не используйте в
рабочей сети.

## Локальный WebUI

Пример compose-файла рассчитан на запуск из каталога `ops/webui` после создания
там `.env` на основе [шаблона](ops/webui/.env.example) и задания уникальных
значений. Не запускайте его поверх
существующих контейнеров/томов, не сверив сначала compose-проект и состояние
PostgreSQL. Операционный порядок и ограничения доступа описаны в
[`ops/webui/README.md`](ops/webui/README.md).
