# Android-планшетный клиент

Для операционного планшета gw2 использовалось отдельное Android-приложение
пакета `org.alco.anet`, сборка `arm64-v8a`, минимальная версия Android 7
(API 24). В локальных материалах отдельно отмечалась проверка на планшете
Android 9/10.

Клиент использует совместимый с gw2 handshake-профиль и параметры маршрутов
из TOML. APK и персональный профиль содержат доверенные/секретные данные и
намеренно не копируются в этот проект. Не распространяйте пользовательский
профиль вместе с исходниками.
